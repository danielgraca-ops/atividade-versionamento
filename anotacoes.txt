Versionamento:
● Guarda o histórico de mudanças de um arquivo ou programa.
● Permite voltar a uma versão antiga se algo der errado.
● Facilita o trabalho em equipe sem perder dados.

Git:
● Software instalado no computador para controlar versões.
● Funciona de forma totalmente local e sem precisar de internet.
● Cria um registro seguro de cada alteração feita no código.

GitHub:
● Site na internet para guardar e compartilhar códigos que usam o Git.
● Ajuda pessoas do mundo todo a colaborarem no mesmo projeto.
● Oferece ferramentas visuais para gerenciar tarefas e problemas.

Diferença Principal
● Git:
○ A ferramenta de controle que roda no seu computador.
○ Gerencia o histórico e o salvamento local do código.

Comandos dos Git 
git init
git add 
git commit -m
git remote add origin
